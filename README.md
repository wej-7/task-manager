## 1. فكرة المشروع

أداة سطر أوامر بلغة Python لإدارة المهام وحفظها في `tasks.json`.

## 2. طريقة التشغيل

من جذر المشروع، شغّل الأوامر التالية:

```bash
python task_manager.py add "قراءة كتاب"
python task_manager.py list
python task_manager.py done 1
python task_manager.py delete 1
```

تضيف `add` مهمة، وتعرض `list` المهام، وتعلّم `done` مهمة كمكتملة، وتحذف `delete` مهمة. استبدل `1` برقم المهمة المطلوب.

## 3. الوكيل والـ Skill

- الوكيل `reviewer`، المعرّف في `.codex/agents/reviewer.toml`، يراجع `task_manager.py` لكشف الأخطاء وحالات الحافة، ويكتب ملاحظاته دون تعديل الكود.
- المهارة `code-review` في `.codex/skills/code-review/SKILL.md` تحدد خطوات قراءة الكود وفحص الأخطاء وحالات الحافة، ثم كتابة تقرير بصيغة: المشكلة، مكانها، الإصلاح المقترح.

## 4. كيف تحققت من النتيجة

- شغّلت المراجع أول مرة فوجد ملاحظتين: قبول أرقام مهام مكررة، والكتابة المباشرة فوق `tasks.json`.
- صححتهما بإضافة تحقق من تفرد الأرقام، والحفظ في ملف مؤقت ثم استبدال الملف الأصلي. جرّبت الأوامر الأربعة وحالة الأرقام المكررة ومحاكاة فشل الحفظ، ثم أعدت `tasks.json` إلى `[]`.
- أعدت المراجعة فتأكد أن الملاحظتين انحلّتا.
- ظهرت ملاحظة جديدة نادرة: رمز Unicode تالف في الوصف عند تعديل الملف خارجيًا قد يسبب استثناء عند الحفظ. تركتها كملاحظة معروفة لأنها خارج نطاق النسخة البسيطة.
