# مراجعة الكود

1. اقرأ `task_manager.py` وافهم الأوامر `add` و`list` و`done` و`delete` وطريقة قراءة `tasks.json` وحفظه.
2. افحص الأخطاء في منطق الأوامر، والتحقق من المدخلات، ومعالجة أخطاء قراءة الملف وحفظه.
3. افحص حالات الحافة: ملف `tasks.json` فارغ تمامًا، قائمة فارغة `[]`، JSON تالف أو بيانات مهام غير صحيحة، رقم مهمة غير موجود، رقم غير صحيح، وصف فارغ، ومعاملات ناقصة أو أمر غير معروف. تتبع مسار التنفيذ لكل حالة وحدد هل تعالجها الأداة بوضوح دون فقدان البيانات.
4. اكتب تقريرًا قصيرًا بالعربية بالمشكلات المؤكدة، واذكر الحالات التي لم تتحقق منها. إذا لم تجد أخطاء، اذكر ذلك بوضوح.

المراجعة للقراءة فقط: لا تعدل الكود أو `tasks.json`، ولا تنفذ أوامر تغير البيانات. اقترح الإصلاحات في التقرير فقط.

## صيغة التقرير

كرر الصيغة التالية لكل مشكلة:

- **المشكلة:** وصف مختصر يتضمن الحالة التي تسببها وأثرها.
- **مكانها:** اسم الملف ورقم السطر أو الدالة المعنية.
- **الإصلاح المقترح:** تغيير محدد ومختصر، دون تنفيذه.
